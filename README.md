# 🎮 Cube Quest - 2D Platformer

**Cube Quest** is a basic 2D platformer built in Unity where players control a cube character to jump between platforms, avoid spikes, and complete levels by reaching the flag. The game includes a title screen, multiple levels, death/restart mechanics, and a win screen.

## Features

- Basic movement and jump controls
- Multi-level progression
- Death on fall or spike contact
- Instant scene reload on death
- Scene transitions via flag
- Title screen + Win screen
- Created by Jasmine Fowler 🎉

## Tech Stack

- Unity 2022.3+
- C#
- TextMeshPro (for UI text)
- Git for version control

## How to Play

1. Run the project in Unity
2. Start at the title screen
3. Use arrow keys or `A/D` to move, `Space` to jump
4. Avoid spikes or falling
5. Reach the flag to move to the next level
6. Beat Level 3 to win!

## 📁 Project Structure
Assets/ ├── Scenes/ # All game scenes ├── Scripts/ # C# scripts (movement, spike, flag) ├── UI Elements # Canvas, DeathText, etc.

## How to Run

1. Clone the repo  
2. Open in Unity Hub  
3. Load `StartScene` from Scenes folder  
4. Press **Play**
